# ABAI · Освоение скважин — мокап

Кликабельный прототип процесса **«Б4. Освоение — умеренный TO BE ОМГ»** на продуктах ABAI.
MVP на чистом HTML/CSS/JS, без сборки и зависимостей: открывается прямо из файла и публикуется на GitHub Pages как есть.

## Источники

- `04_4. Освоение.bpmn`: три пула (AS IS, умеренный TO BE ОМГ, TO BE Nedra), дорожки, шаги 4.0–4.5, хранилища данных и аннотации.
- `18.09.2026_Страт. сессия ЭМГ.pptx`: слайд 39 (освоение, AS IS / TO BE), 34 (соответствие ABAI ↔ Nedra), 54 (КХД как слой интеграций), скриншоты ABAI (визуальный стиль).

## Что есть в мокапе

| Экран | Что показывает |
|---|---|
| **Реестр освоения** | Скважины на освоении, группировка по этапам, текущий шаг, ответственная роль, прогресс |
| **Мои задачи** | Скважины, где следующий шаг — за выбранной ролью |
| **Цифровое дело скважины** | Пошаговый процесс (10 шагов + подшаги 4.4.1–4.4.4), документы, журнал, системы на каждом шаге |
| **Процесс AS IS → TO BE** | Сравнение трёх вариантов из BPMN, дорожки TO BE, матрица систем по шагам |

Ключевые сценарии TO BE:
- загрузка акта приёмки в ABAI БД 2.0 и приёмка скважины геологом с чек-листом;
- подписание ЭЦП через NCA Layer (имитация окна NCALayer): акт приёмки, программа освоения, АВР;
- возврат на доработку с комментарием (при приёмке и согласовании программы);
- цифровая отчётность по операциям освоения: ГИС, перфорация и промывка, спуск воронки и гидромуфты, приток; данные уходят в ABAI БД 2.0 и ABAI ТР;
- 30 суток наблюдения: суточный отчёт SCADA → ABAI ТР, график с подсказками и таблица;
- сравнение с соседними скважинами в ABAI ТР 2.0;
- закрытие дела: АВР+ → КП 2.0 (паспорт) → КХД.

**Роль переключается вверху справа**: Подрядная организация / Геологи ОМГ / ОМГ (ДЗО). Если шаг принадлежит другой роли, в панели шага есть кнопка «Переключиться на эту роль».
Для прохода «с нуля» откройте скв. **7412**: она стоит на первом шаге. Кнопки «Заполнить демо-данными» ускоряют показ.

Состояние хранится в `localStorage` браузера, кнопка **«Сбросить демо»** есть в реестре.

## Запуск

Откройте `index.html` в браузере. Можно и через локальный сервер:

```bash
python -m http.server 8000
# http://localhost:8000
```

## Публикация на GitHub Pages

```bash
git remote add origin https://github.com/<user>/abai-osvoenie.git
git push -u origin main
```

Дальше: Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
Файл `.nojekyll` уже лежит в корне.

## Структура

```
index.html
css/app.css      стили (в духе интерфейса ABAI)
js/data.js       роли, системы, шаги процесса, демо-скважины
js/charts.js     SVG-графики без зависимостей (линия + столбцы, подсказки)
js/app.js        роутинг, экраны, сценарии действий
```

Если понадобится React: `data.js` переносится как есть, экраны из `app.js` раскладываются на компоненты
(`Registry`, `WellCase`, `StepPanel`, `NcaSignModal`, `ProcessPage`), а `localStorage` заменяется API.

Все данные демонстрационные: скважины, подрядчик, ФИО и показатели вымышлены.
